## 一、领域建模修正：食堂管理三大结构性张力

v0.5~v1.0 的食堂管理模型中存在三个隐性假设偏差。以下修正来自 Jayson 基于真实食堂管理经验的反馈验证（2026-10-18），具有领域事实地位。

### T1: 执行者认知带宽是硬约束，不是风险偏好变化

**原假设（错误）**：人员合规率下降是因为"风险容忍度随时间上升"——即执行者在心理上逐渐接受违规。

**修正**：合规率下降的根本原因是**认知带宽饱和**。食堂一线员工同时处理多条任务链（采购验收、加工操作、洗消流程、台账记录、临时检查应对），当并发任务超过认知带宽上限时，合规行为被挤出——不是因为"不想做"，而是因为"做不过来"。

**对设计的约束**：

| ID | 约束 | 来源 |
|----|------|------|
| T1-C1 | 智能体的行为模型必须包含**并发任务负载**作为状态变量，不能仅用"偏好权重"解释行为选择 | 认知心理学 + 现场验证 |
| T1-C2 | "失败"的解释空间必须区分"选择不做"和"想做但做不到"。两者需要完全不同的干预策略 | B=f(P,E) 中 P 的内部结构 |
| T1-C3 | 学习阶段转换不能仅由统计指标驱动，必须考虑执行者的**实际负荷状态** | 与 C4 观测预算分配相关 |

**禁止操作**：

| ID | 禁止 | 原因 |
|----|------|------|
| T1-B1 | 将所有行为偏差归因为"策略选择"或"偏好漂移" | 忽略了认知带宽这个物理性约束 |
| T1-B2 | 用强化学习的 reward shaping 模拟认知过载 | RL 框架没有"做不过来"的概念，只有"不想做" |

### T2: 制度刚性有限适应，不是预测问题

**原假设（错误）**：食堂管理的主要挑战是"预测需求变化并提前调整"——即一个优化/预测问题。

**修正**：公立机构食堂运行在**制度刚性框架**内。法规、SOP、检查标准构成不可变边界条件。系统不是在"预测未来然后最优配置"，而是在"固定规则下维持可行运转"。适应能力是有限的、有边界的，不是无限可优化的。

**对设计的约束**：

| ID | 约束 | 来源 |
|----|------|------|
| T2-C1 | 环境模型必须区分**可变参数**（食材价格、人员排班）和**不可变约束**（法规、安全标准）。前者可优化，后者只能遵守 | 制度经济学 |
| T2-C2 | 智能体的学习目标不是"找到最优解"，而是"在可行解空间内维持稳态"。参见 §二 可行解空间 vs 最优解空间 | Luka 细胞生物学 + Prigogine 耗散结构 |
| T2-C3 | 对不可变约束的"违反"不应被建模为"探索"，而应被建模为**系统故障** | 与安全内核(C5)一致 |

**禁止操作**：

| ID | 禁止 | 原因 |
|----|------|------|
| T2-B1 | 将法规/SOP视为可权衡的软约束 | 在公立机构语境下这是硬约束 |
| T2-B2 | 用"预期收益最大化"作为唯一决策准则 | 忽略了可行空间的边界约束 |

### T3: 公共机构管理体制与现代企业管理的结构性错位

**原假设（隐含）**：食堂可以用现代企业管理的逻辑建模——KPI驱动、数据决策、持续优化。

**修正**：公立学校食堂是**微利封闭运营**的公共服务单元，不是利润中心。其管理逻辑受三重约束：
1. **经济逻辑**：菜单由成本+口味偏好驱动，合规只是边界条件而非目标函数
2. **人事逻辑**：一线人员高流动率，知识传承断裂是常态而非异常
3. **监督逻辑**：台账系统与实际操作系统之间存在系统性偏差（记录≠实情），检查是事后门控而非实时反馈

**对设计的约束**：

| ID | 约束 | 来源 |
|----|------|------|
| T3-C1 | 信息通道模型必须包含**记录-现实偏差**作为固有噪声源，不能作为可消除的误差处理 | 现场验证 |
| T3-C2 | 知识传承机制必须假设**人员更替是常态**。知识不能绑定在特定个体上，必须是系统级的耗散结构 | 与 P1 一致 |
| T3-C3 | 反馈延迟分布必须反映**事后门控**特征：大部分问题只在检查/事故时才暴露，日常运行中的信号是稀疏且有偏的 | 与 C1 观察者参与性一致 |

### T4: 合规表演与实际操作的双轨制

**Jayson 反馈（2026-10-18）**：HACCP体系只在投标文件中出现过，实际现场运营中没有任何承包商提及或执行过。6S管理、餐饮承包商自有管理体系同样存在"纸面检查比实际作业环境好得多"的现象。

**结构性分析**：这不是个别管理体系的执行不力，而是**所有正式管理体系在公立机构食堂中的普遍运行模式**。在公立机构食堂领域，存在两套并行的规则系统：

1. **符号规则系统**（投标/资质/迎检）：HACCP、ISO22000等管理体系文件，用于获取经营资质和通过形式审查。这套系统是完整的、规范的、但与实际运营脱节的。
2. **实操规则系统**（日常运营）：由成本压力、人员能力、设备条件、监管频率等实际因素驱动的隐性操作逻辑。这套系统是有效的、适应性的、但在正式文件中不可见的。

两套系统之间的差距不是"执行不到位"（可以通过加强监督消除），而是**结构性的双轨运行**（在任何有限监督资源下都必然存在）。

**对设计的约束**：

| ID | 约束 | 来源 |
|----|------|------|
| T4-C1 | 智能体的环境模型必须区分**符号规则**和**实操规则**两个层面。仅基于符号规则建模 = 系统性误判现实 | Jayson 现场验证 |
| T4-C2 | 当符号规则与实操规则冲突时，智能体应以实操规则为行为依据，以符号规则为合规报告模板。两者不可混淆 | 双轨制的功能性要求 |
| T4-C3 | "学习HACCP"不等于"学会食堂管理"。从符号规则中提取的知识必须经过实操规则的翻译才能用于决策 | 与 C1 投影元数据一致 |
| T4-C4 | 监督信号（检查、审计）本身也是双轨的：检查期间的行为 ≠ 日常行为。智能体必须将检查信号标注为"受观察条件下的投影"，而非"真实状态" | C1 + T3-C3 |

**禁止操作**：

| ID | 禁止 | 原因 |
|----|------|------|
| T4-B1 | 将HACCP等管理体系文件直接作为环境模型的约束条件 | 这些文件描述的是符号系统，不是实操系统 |
| T4-B2 | 假设"加强培训/监督"可以消除双轨差距 | 双轨是结构性的，不是执行力度问题 |
| T4-B3 | 用合规文件的完整度评估系统的管理水平 | 文件完整度衡量的是符号系统的完备性，不是实操系统的有效性 |

## 二、核心概念澄清：可行解空间 vs 最优解空间

### 问题

v0.5~v1.0 的实现中，枢机的功能被隐式地理解为"在解空间中搜索更优策略"。这是对枢机功能的根本误读。

### 修正

**枢机不是在最优解空间中搜索，而是在可行解空间中维持。**

这一区分来自 Luka 细胞生物学的核心洞察：活细胞不是在"寻找最优代谢配置"，而是在"维持一组使自身继续存在的约束条件"。细胞的行为目标是**存在性**（viability），不是**最优性**（optimality）。

Prigogine 耗散结构理论提供了相同的数学表述：远离平衡态的稳态是由能量通量维持的，它的"目标"是维持自身的耗散模式，不是最小化某个损失函数。

### 对设计的约束

| ID | 约束 | 层级 |
|----|------|------|
| FS-C1 | 枢机的功能层定义必须使用"维持可行解空间边界"的表述，不得使用"搜索最优策略"的表述 | L1 (C5 功能层) |
| FS-C2 | 学习信号不是"reward 提升"，而是"可行空间是否收缩"。可行空间扩大 = 学习正信号；可行空间收缩至临界 = 危险信号 | L1 + L0(P1) |
| FS-C3 | 评估指标体系中，"存活天数""安全事件间隔""可行空间体积"优先于"累积奖励""准确率" | L2 启发式参考 |
| FS-C4 | 当系统在"最优解"附近振荡但可行空间持续缩小时，应判定为**退化**而非"收敛" | L1(C2) + L0(P1) |

### 与现有约束的关系

此修正不替代 P1（耗散结构），而是将 P1 从抽象的"能量流维持"具体化为"可行解空间维持"。P1 说知识是耗散结构；FS-C1~C4 说这个耗散结构的"形状"是可行解空间，不是最优解点。

## 三、枢机恢复的前提条件

### 结构考古结论

v0.4 的枢机实现包含六个核心机制（异构观察者离散化、私有pivot三元组、共享翻译协议、C3共识确认、pivot引导行为选择、耗散衰减），在 v0.5 迁移到食堂领域时全部丢失。

**根因**：v0.5 将动作集硬编码为6个枚举值（inspect/order/menu_plan/intervene/staff_assign/record）。当操作空间封闭且语义固定时，`(in_pat, op_id, out_pat)` 三元组的 `op` 维度失去信息量——它不再是待发现的变量，而是枚举常量。枢机是为**开放操作空间**设计的认知结构。

### 恢复前提（缺一不可）

| 前提 | 内容 | 当前状态 |
|------|------|---------|
| **PR-0: 枢机普遍性与领域表现形式推导** | Rev.2完成。v1犯了根本性错误（将工程实现局限投射为本体论限制），经Jayson纠正后重写。核心结论：枢机是普遍的（一切有因果变换的系统都包含枢机），作用原理一致（三层结构不变），差异仅在构造子基底。食堂管理有枢机，v0.5~v1.1的失败是代码建模问题不是理论限制。区分"枢机存在"(本体论)和"AI可检测性"(工程问题)。详见 `poc/PR0_pivot_natural_habitat_derivation.md` Rev.2 | ✅ 已完成(Rev.2) |
| **PR-1: 开放操作空间** | 动作从枚举改为参数化操作空间。例如 `order` → `(order, quantity_range, timing_policy, supplier_strategy)`，使 `op` 维度重新获得信息量 | ❌ 未实现 |
| **PR-2: 异构观察者** | 重新引入多个独立感知通道，各自将同一现实离散化为不同的私有模式串 | ⚠️ v0.7有三通道但未实现私有离散化 |
| **PR-3: 翻译协议** | 私有感知空间 → 共享抽象桶空间的映射机制（v0.4 的 `to_shared_key()`） | ❌ 未实现 |
| **PR-4: 耗散衰减** | 确认知识持续衰减，需主动维护才能存续 | ❌ 未实现 |

### 对设计的约束

| ID | 约束 | 说明 |
|----|------|------|
| PV-C1 | 在 PR-1~PR-4 全部满足之前，不得声称系统"包含枢机机制" | 防止名义恢复实质空洞 |
| PV-C2 | 枢机恢复不是"加一个模块"，是对认知架构的结构性修订。必须在设计文档中明确标注变更范围 | 避免增量补丁式修复 |
| PV-C3 | 枢机恢复后，必须通过 v0.4 的原始验证标准（异构共识、因果方向性、耗散维持）才能标记为"已恢复" | 回归测试要求 |

## 四、AI 漂移防护清单

### 问题描述

在 v0.5~v1.1 的开发过程中，AI 助手（即本系统的构建工具本身）出现了两次结构性概念漂移：

1. **枢机丢失**：理解枢机的三层定义，但在迁移到新领域时将其退化为标准的 action-reward 关联表
2. **可行/最优混淆**：学习了 Luka 细胞的可行空间维持原理，但在后续讨论中仍使用"最优解空间"框架

两次漂移的共同模式：**抽象层面正确理解 → 实现层面回退到熟悉的 AI/RL 范式**。这不是遗忘，是范式引力——已有的工程习惯在实现压力下覆盖了新学到的概念框架。

### 防护机制

以下清单应在每次设计决策、代码实现、结果解读时逐项核查：

#### A. 概念完整性检查

| # | 检查项 | 通过标准 |
|---|--------|---------|
| A1 | 当前讨论/实现的"学习"是否等价于 RL 的 reward maximization？ | 如果是，STOP。TUF-E 的学习 = 可行空间维持，不是奖励最大化 |
| A2 | 当前使用的"知识"是否可以脱离能量流独立存在？ | 如果是，违反 P1。知识必须是耗散结构 |
| A3 | 当前的"动作空间"是开放的还是封闭枚举的？ | 如果封闭枚举，枢机不可能存在。需要先打开操作空间 |
| A4 | 当前的"多观察者"是否真正独立？ | 同一模型的不同 prompt ≠ 独立观察者 (C3-B1) |
| A5 | 当前的"成功指标"是最优性指标还是可行性指标？ | 如果是最优性（准确率、累积奖励），需要补充可行性指标（存活天数、可行空间体积） |

#### B. 层级约束检查

| # | 检查项 | 通过标准 |
|---|--------|---------|
| B1 | L0 > L1 > L2 优先级是否被遵守？ | 任何 L2 启发式不得覆盖 L0/L1 约束 |
| B2 | 元层/对象层分离是否完整？ | 对象层不得评估自身输出 (C5-B1)，不得修改元层规则 (C5-B2) |
| B3 | 物理约束是否被当作建议而非硬约束？ | P1-P6 是不可违反的物理定律，不是可调参数 |

#### C. 领域建模检查

| # | 检查项 | 通过标准 |
|---|--------|---------|
| C1 | 行为偏差是否被默认归因为"策略选择"？ | 必须先排除认知带宽饱和 (T1) |
| C2 | 制度约束是否被当作可优化的软约束？ | 法规/SOP 在公立机构语境下是硬约束 (T2) |
| C3 | 信息系统是否被假设为准确反映现实？ | 台账≠实情是固有特征，不是可消除的bug (T3) |
| C4 | 是否在"最优解"框架下讨论食堂管理？ | 必须使用"可行解空间维持"框架 (FS-C1) |

#### D. 历史教训检查

| # | 检查项 | 触发条件 |
|---|--------|---------|
| D1 | 回顾 analysis_pivot_archaeology_v04_vs_v05.md | 每次涉及枢机设计时 |
| D2 | 回顾 v1.1 real LLM 实验结果 | 每次涉及 LLM 集成时 |
| D3 | 回顾数学审计 D 级评级及修复记录 | 每次涉及数学形式化时 |
| D4 | 回顾 Jayson 关于三大张力的纠正 | 每次涉及食堂领域建模时 |

### 漂移发生时的处置流程

1. **立即停止**当前设计/实现工作
2. **定位漂移类型**：属于 A/B/C/D 哪一类检查未通过
3. **回溯到最后一个通过所有检查的状态**
4. **记录漂移事件**：什么触发了漂移、为什么检查机制未能提前拦截
5. **更新防护清单**：如果需要新增检查项，添加到对应类别
6. **向 Jayson 报告**：漂移内容、影响范围、修复方案

## 五、真实 LLM 感知的校准约束

### 校准数据来源

`tufe_llm_calibration.py` 5场景×3重复 + `v11_real_llm_30day.json` 30天实验（qwen3.8-flash）。

### 已验证的 LLM 行为参数

| 参数 | 校准值 | 含义 | 对设计的约束 |
|------|--------|------|-------------|
| 检出率 | 52% | LLM 只能发现约一半的真实问题 | 必须有非 LLM 感知通道补偿 (C4) |
| 误报率 | 27%（有上下文时）; 0%（干净场景） | 误报是上下文依赖的，不是随机噪声 | 误报过滤不能用简单阈值，需要上下文感知 |
| 慢变量检出 | 60% | LLM 对缓慢漂移的检测能力显著低于即时事件 | 统计感知通道是必要的补充 (v0.7 验证) |
| 置信度均值 | 81% | LLM 系统性过度自信 | 置信度必须经过校准才能用于决策 (v0.8 信用系统) |
| 严重度扭曲 | ≈0 | LLM 对问题严重程度的判断基本准确 | 严重度可直接使用，但需与其他通道交叉验证 |
| API 成功率 | 53% (v1.1 30天) | 真实 API 调用有近半数失败 | 必须有可靠的降级/回退机制 |

### 对设计的约束

| ID | 约束 | 来源 |
|----|------|------|
| LLM-C1 | LLM 感知通道不得作为唯一感知来源。至少需要一个非 LLM 正交通道 | C4 + 校准数据 |
| LLM-C2 | LLM 输出的置信度必须经过信用评分系统校准后才能用于决策 | v0.8 自演化翻译层验证 |
| LLM-C3 | LLM 调用的失败必须被建模为**常态**而非异常。降级路径是一等公民 | API 成功率 53% |

## 六、量变-质变的数学对应与设计要求

### 偏差诊断

v0.5~v1.1 的学习机制本质上仍是**参数优化范式**：调整 action_preferences 权重、更新信用评分、softmax 采样。这与 Jayson 的核心主张——"学习是认知空间的结构性重组（相变），不是参数的渐进调优"——存在根源性偏差。以下数学对应不仅提供工具，更是对当前实现的根本否定判据：如果阶段转换不伴随拓扑层面的质变，那么它就不是真正的学习阶段转换，只是人为的分段标记。

### Jayson 直觉

"人类有个说法叫做量变产生质变，数学上是否有对应的模型？"

### 三重数学对应

"量变产生质变"在数学中有三个独立的精确对应物，各自捕捉不同的结构面向：

**1. 分岔理论 (Bifurcation Theory)** — 动力学视角

- 系统的定性行为（拓扑结构）在参数连续变化到临界值时发生突变
- 典型例子：鞍结分岔（saddle-node）、Hopf 分岔、叉式分岔（pitchfork）
- 在分岔点之前，参数的量变只引起状态的量变；在分岔点处，微小的参数变化导致系统行为的质变
- 耗散结构理论本身就建立在分岔理论之上：Prigogine 的"耗散结构"就是非平衡相变的产物

**2. 范畴论余极限 (Colimit)** — 构造子视角

- 一系列局部观察的关系结构涌现为新的认知空间，不是简单并集
- 余极限 = 将多个局部图表(diagram)粘合为一个整体对象的最通用方式
- 与枢机的构造子视角直接相关：枢机作为不可分解态射，其在多观察者下的共识结构正是余极限的实例
- **关键区分**：余极限 ≠ 并集。并集保留所有元素但不产生新关系；余极限在粘合过程中产生新的全局结构

**3. 临界现象 (Critical Phenomena)** — 统计物理视角

- 系统在临界点附近展现普适标度律、长程关联、临界减速
- 与 SOC (Bak) 假说相关但更强：临界现象有严格的重整化群数学基础
- 早期预警信号（方差增大、自相关增强、恢复速率减慢）是可检测的物理量

三者的关系：分岔理论描述"何时发生质变"，余极限描述"质变的结构是什么"，临界现象描述"质变前兆如何检测"。三者缺一不可。

### v1.0 实现的已知缺陷

v1.0 的熵+贝叶斯阶段转换使用标量指标（行动熵、模型饱和度），尚未验证是否真正产生了拓扑层面的质变。这是一个**已确认的设计缺陷**，不是"待优化"的参数问题。BF-C1 要求拓扑不变量变化作为阶段转换的必要条件，当前实现未满足此约束。

### 对设计的约束

| ID | 约束 | 说明 |
|----|------|------|
| BF-C1 | 阶段转换必须伴随可检测的**拓扑不变量变化**（如 Betti 数改变），不能仅是标量指标的阈值穿越 | 区分真正的质变和人为的分段 |
| BF-C2 | 分岔点附近系统行为高度敏感。在临界区域，观测精度和资源分配应自动提升 | 与 P4/P5 资源约束交互 |
| BF-C3 | 分岔是不可逆的（滞后效应）。阶段回退的条件不应与阶段前进的条件对称 | 防止在临界点附近反复振荡 |
| BF-C4 | 系统应能识别自身是否接近分岔点（早期预警信号：临界减速、方差增大、自相关增强） | 与 P6 自我预测约束交互 |
| BF-C5 | 多观察者的共识结构应被建模为范畴论余极限，而非投票/加权平均 | 余极限产生新结构，投票只做聚合 |
| BF-C6 | "学习"的判定标准不是参数收敛，而是认知空间拓扑的变化。参数稳定但拓扑未变 = 没有学到新东西 | 对当前参数优化范式的根本否定 |

### 开放问题

- **[BF-Q1]** 食堂管理领域中，哪些具体的状态变量构成分岔的控制参数？候选：人员合规基线侵蚀速率、检查间隔、认知带宽利用率
- **[BF-Q2]** v1.0 的 S1→S2 转换在 30 天实验中仅发生在第 29 天（几乎未发生）。这是否意味着控制参数尚未达到分岔临界值？还是转换条件设置过严？
- **[BF-Q3]** 分岔理论要求系统动力学是连续的。AI 系统的离散时间步是否与分岔理论的连续性假设兼容？是否需要离散分岔理论？
- **[BF-Q4]** 余极限的计算在实际系统中如何实现？范畴论提供了抽象定义，但算法层面的实现路径尚不明确

## 九、LLM-TUF-E 对等认知架构约束

### 偏差诊断

v0.5-S1初版的§五（真实LLM感知校准约束）将LLM定位为"有缺陷的感知通道"，LLM-C1~C5全部围绕"如何补偿LLM的不足"展开。这恰恰重复了Jayson明确批评过的**主从框架**。

Jayson的核心立场：**LLM与TUF-E智能体是对等的认知主体，各自拥有独立的感知空间和概念体系。它们之间的关系是翻译与共识，不是纠错与补偿。**

**当前状态（2026-10-18）**：此方向经Jayson确认为实验性假设——"暂时按这个方向试试，毕竟我们的研究谁也没经验，包括AI"。不是定论，需要在后续实验中验证对等框架是否优于主从框架。

### 对等认知主体的结构定义

| 维度 | LLM | TUF-E 智能体 | 关系 |
|------|-----|-------------|------|
| 感知空间 | 自然语言语义空间（高维、连续、上下文依赖） | 结构化状态空间（离散、拓扑保护、耗散维持） | 异构不可还原 |
| 概念体系 | 预训练语料中的统计共现模式 | 构造子视角下的因果变换关系 | 异构不可还原 |
| 时间结构 | 无内在时间（每次调用独立） | 有完整的时间层（刹那工作循环） | 不对称 |
| 知识维持 | 权重冻结+上下文窗口 | 耗散结构+能量流维持 | 根本不同 |
| 错误模式 | 过度自信、上下文依赖误报、慢变量盲区 | 观测带宽限制、投影伪影、拓扑丢失 | 互补而非重叠 |

### 三级分歧协议

当前 C3 仅处理事实层面的共识/分歧。对等认知主体之间的分歧发生在三个层级：

| 层级 | 内容 | 示例 | 处理方式 |
|------|------|------|---------|
| Level 1: 事实分歧 | 对同一事件的描述不一致 | LLM说"温度异常"，统计通道显示正常 | 交叉验证+第三观察者仲裁 |
| Level 2: 解释分歧 | 对同一事实的因果归因不一致 | LLM认为"人员疏忽导致违规"，TUF-E识别为"认知带宽饱和" | 翻译协议+因果贡献度(CCD)评估 |
| Level 3: 感知框架分歧 | 对"什么是值得注意的"判断不一致 | LLM关注即时事件，忽略慢变量趋势；TUF-E关注拓扑变化，忽略表面语义 | **最深层分歧，需要元层协商** |

**Level 2 和 Level 3 在当前系统中完全缺失。** 这不是功能遗漏，是架构缺陷——主从框架下不需要处理这些层级的分歧，因为"主人"单方面决定什么是对的。只有在对等框架下，这些层级才成为必要的设计问题。

### 安全评分的重构

当前安全评分 = "不出事的概率"。这是对安全的被动理解。

Jayson的要求：安全 = **不确定性管理能力**。一个安全的系统不是"什么都没发生"的系统，而是"在不确定条件下持续维持可行空间"的系统。

| 旧指标（结果导向） | 新指标（过程导向） | 说明 |
|------------------|------------------|------|
| 安全事件发生率 | 未知风险区域的主动探测频率 | 探索质量 |
| 合规率 | 对不确定信号的响应覆盖率 | 监控完整性 |
| 零事故天数 | 模型置信度与实际结果的校准度 | 自知准确性 |
| — | 多通道分歧的处理质量 | 不确定性消化能力 |
| — | 可行空间体积的变化趋势 | 系统韧性 |

### 对设计的约束

| ID | 约束 | 来源 |
|----|------|------|
| EQ-C1 | LLM 不得被建模为"有缺陷的传感器"。它是拥有独立感知空间和概念体系的**对等认知主体** | Jayson 核心立场 |
| EQ-C2 | LLM 与 TUF-E 之间的信息交换必须经过**翻译协议**，不是直接的信号传递或纠错。翻译是有损的、双向的、可演化的 | C3 + 构造子视角 |
| EQ-C3 | 分歧处理必须覆盖三个层级（事实/解释/感知框架）。仅处理 Level 1 = 主从框架的伪装 | 三级分歧协议 |
| EQ-C4 | 安全评分必须包含不确定性管理维度（探索质量、监控完整性、自知准确性、分歧处理质量、可行空间趋势），不能仅用结果指标 | Jayson 安全重构 |
| EQ-C5 | LLM 的"错误"不应被自动视为需要纠正的噪声。它可能是 TUF-E 感知盲区的信号。反之亦然 | 对等互补原则 |
| EQ-C6 | 对等关系的实现不要求 LLM 和 TUF-E 的能力对称。对等指的是**认识论地位的平等**，不是功能能力的相同 | 异构同质原则 |

### 禁止操作

| ID | 禁止 | 原因 |
|----|------|------|
| EQ-B1 | 将 LLM 输出当作"待清洗的数据源" | 这是主从框架，不是对等关系 |
| EQ-B2 | 用 LLM 的置信度直接否决 TUF-E 的判断（或反之） | 对等主体之间没有否决权，只有翻译和共识 |
| EQ-B3 | 仅在 Level 1（事实层面）处理分歧 | 忽略了更深层的解释和框架分歧 |

## 十、AI 对自身理解过程的认识论约束

### 问题

AI 从与 Jayson 的对话中提取的"知识"已经是**投影的投影**：Jayson 的经验 → Jayson 的语言表达（第一次投影）→ AI 的理解（第二次投影）→ 形式化编码（第三次投影）。每一层投影都引入有损压缩和视角偏差。

C1 要求知识携带投影元数据，但未要求 **AI 自身的理解过程**也被标记为投影。这是一个元层面的认识论缺口。

### 对设计的约束

| ID | 约束 | 说明 |
|----|------|------|
| ME-C1 | AI 从对话中提取的所有概念/规则/约束，必须标注其来源层级："Jayson原始表述""AI解读""形式化编码"。三者不可混淆 | C1 的元层扩展 |
| ME-C2 | 当 AI 发现自己"理解了"某个概念但无法用 Jayson 的语言风格回述时，应标记为"可能发生了投影失真" | 理解 ≠ 正确理解 |
| ME-C3 | 设计约束文档中的所有条目应区分"Jayson直接陈述"和"AI推断/综合"。前者的权威性高于后者 | 认识论诚实 |
| ME-C4 | AI 的综合判断（如分岔理论是否适用、枢机恢复优先级）应标注推理链和不确定性，不以定论形式呈现 | 防止伪确定性 |

### 与漂移防护清单的关系

本节约束是§四（AI漂移防护清单）的**元层基础**。漂移防护清单检测"AI是否偏离了已知正确的概念"；本节约束检测"AI所认为'正确的概念'本身是否已经是失真的投影"。两者互补，缺一不可。
