## 一、我们最初到底想干什么

设计语言 v0.1 曾被写成"怎么组装一个能做事的 AI"。Jayson 纠正：正确定位应是
**"枢机在什么条件下会自己长出来"的形式化表达**。

锚定这件事的那个比方：

> "如果人类大学生都可以快速复制出来，那么设置小学、初中、高中的意义在哪？"

**初衷（一句话）**：研究的不是"造一个能做事的成品 AI"，而是
**"能力怎么从无到有、从简单到复杂自己涌现出来的那个生长过程本身"**。
重心是 **"什么条件下生长会发生"**，不是"怎么构建"。

配套的本体论立场：
- TUF-E 本体论优先，**枢机普遍存在是起点**（PR-0）；AlphaGo / LUCA 是对照参照系，不是抄的来源。
- 三个"独一份"的主张：知识是**耗散结构**不是累积知识库；学习是**可行空间维持**不是奖励最大化；目标是**非奖励驱动**的。

## 二、这一路成果给初衷带来了什么

不是"改变"初衷，是把它**精确化**，并逼它做了一次**自我纠偏**。分四层。

### 第一层：从"一张条件清单"→"逐条证伪 + 撞出清单里没有的新条件"

当初列了六个生长条件（开放操作空间 / 独立感知构造子 / 耗散知识 / 拓扑重组学习 /
不可修改的元层 / 可行空间为目标）。一路实验下来，好几条被证明"必要但不充分"，
同时挖出了原来完全没想到的硬条件：

| 新条件 | 来自 | 大白话 |
|---|---|---|
| 知识要能在**合适粒度上被重新寻址** | SC-1 / SC-2 | 学到的东西得调得出来，粒度太粗太细都白学 |
| 真正瓶颈是**生成/发现**，不是选择 | v1.11 | 池子里根本没有好方法时，选择规则改得再对也没用 |
| **环境太仁慈 = 学习幻觉** | v1.5 / OC-9 | 表演满分、真本事为零；环境替你活，你就没长本事 |
| 能力只在**环境供给掉到阈值以下**才真长 | v1.6 / M10 | 离开"喷口"才第一次形成自己的本事；且逃逸有路径依赖 |
| **封闭固定算法不产生新信息** | OC-12 | 生长必须有外部信息门（环境 / 随机 / 人） |

### 第二层（最深）：初衷做了一次自我净化

Jayson 说"研究过程、不研究成品"。但直到 v1.13 我才发现——
**连"怎么量生长"都偷偷退回了成品思维**：每轮打贏/输、算成功率、拿 oracle 满分当天花板、
用"保留赢家"当适应度。这等于用"期末考了多少分"去研究"一个孩子怎么长大"。

Jayson 追问"为什么用赢输理论？LUCA 知不知道自己未来？"一下把这个盲区照出来了：
**要真研究"生长过程"，就得彻底放弃"有靶、有满分参照"的尺子——LUCA 从来不知道自己要变成什么。**

这是初衷自己抓出的第四次漂移（前三次：枢机丢失 / 可行-最优混淆 / 工程局限当本体论限制），
也是**框架层最深的一次**。已写进漂移预防协议。

### 第三层：从"希望能力涌现"→"亲眼看到一丝内生结晶，且知道它精确的边界和死法"

- **v1.12**：一个"探→记住排除→再探"的闭环策略，**在没注入任何答案的情况下自己长出来了**
  （约为不学习地板的 2–3 倍）。内生结晶**被证明会发生**。
- **v1.13**：证明它是**真的**（超额因果有效性为正，非学习幻觉），但**还不可持续**，并精确指出两个卡点：
  - **F1 饱和天花板**：世界太小（6 通道，<40 个催化剂就覆盖满）→ 结晶爆发一阵就没了。
    **可持续结晶需要一个"学不完"的环境（组合开放的可行空间）。**
  - **F2 中漂移脆弱共振**：存活率对环境变化速度是 **U 形**——两头稳、中间塌。
    环境不变→安全特化但冻住；变化太快→被逼着保持泛化多样性反而活；
    **中等变化最致命**→慢到让你过度特化、又快到迟早撞上你应付不了的局面，且它持续得比你重新学还久。

### 第四层：方法论成熟了

跑通了一个闭环：**从生物 / 物理 / 古籍蒸馏一个模型 → 变成预注册的可证伪实验 →
不管成败都产出一个可复用的诊断工具**。
产出的诊断工具：学习幻觉探测器（fire-viable vs 背景率）、最小作用量分解、
超额因果有效性（OC-9）、U 形脆弱带。

而且**失败和成功一样高产**：v1.9 假墙、v1.10 误读费马、v1.11 无增益、v1.13 无带——
每个"错"都逼出一条新认识。Jayson 那句"错误也是学习的一种方式"，现在被制度化执行
（预注册先于结果提交、失败如实作主产出、不为赢续命调参）。

## 三、诚实说：还没兑现的部分

初衷里那三个"独一份"的主张——**没被推翻，但也还没真正做成一个"能持续生长"的系统**。
v1.13 的结论就是：**我们现在还不能维持可持续的内生结晶**。
两条腿已经识别出来、但还没建：
1. 一个**学不完的环境**（组合开放的可行空间）；
2. 一个**防止过度特化侵蚀多样性缓冲**的机制。

## 五、增补（v1.14–v1.15）：信誉门槛补上了，但蓝图正中央没动

§一~§四 写于 v1.13 收口。之后又走了两步，都属**回应 v1.0 外部评审的信誉 program（package-v1.1）**，
不是攻生长本身，故在此如实增补，避免把"机制可信度进展"误当"可持续生长进展"。

- **v1.14（H-NOADV，诚实负）**：精确全状态寻址"一点火就 100% 因果正确"（fire-viable 1.000、OC-9 超额 0.864），
  但只点火 22–26%，总体只比状态盲天花板高 0.031，**未达自冻的 0.10 边界**。诊断（第一档 measured）：
  **瓶颈是 COVERAGE 不是 MECHANISM**。
- **v1.15（H-OPTIMUM，首个 ask #4 干净正例）**：用 SC-2 **骨架寻址**（只看目标幅值的粗档）把点火覆盖拉到 76%，
  在同一任务/同 seed/同基线下把状态条件枢机推到 **0.656 ≈ 状态盲天花板（0.336）的 2 倍**，
  **同时胜 random / no-op / best-fixed / 状态盲赌博机（五数同表）**。机制＝**有用点火乘积 fire_rate × fire_viable**，
  **证实**（非推翻）v1.14 诊断。P-COVERAGE 如实 FAIL（点火率受**组纯度**支配，非组数）——自己预注册的机制叙事被自己证伪一半。
  路径出处：冷启动 + 跨 seed 重演一致性 1.0 + 事后 op 恢复 CONVERGENT；但**单步 arithmetic 出处很薄**，且 agent **不理解算术**
  （学的是"目标大概多大→用哪个 op"的粗耦合，钻 op 值域差异的空子），**远非掌握一门学科**。

### 蓝图 vs 现状：一个必须点明的错位

Jayson 问"进度和最初蓝图对得上吗"。对着 v0.1（历史起点）与 v0.3（当前活蓝图）逐条核，诚实答案分三层：

1. **对起源初衷（研究"能力怎么自己长出来"）——对得上，且越来越贴合。** v1.13 非目的论纠偏把它从"分数思维"拉回，
   v1.14/v1.15 延续证伪闭环方法论（预注册先于结果、失败如实作主产出、不为赢调参）。
2. **对 v0.1 技术蓝图——部分对不上，且是真实错位：** 最近的漂亮结果**跑在 v0.1 里根本没有的一条侧枝上**
   （因果记忆寻址 SC-1/SC-2）；而 v0.1 正中央主打的**共识（R3）+ 拓扑判据（R7）被证明有裂缝、目前搁置**
   （R7＝Betti churn；共识在连续域负效应）。**⇒ 我们在蓝图边上长出一条更结实的新枝，主干那棵树却病了。**
   已对 v0.1 做**定点诚实订正**（加状态横幅，不改正文，声明 v0.3＝当前活蓝图），**不做美化式全面重写**。
3. **对初衷最核心的未竟问题（能不能"持续生长"）——没前进，仍停在 v1.13 原地。** §三 说的两条腿
   （① 学不完的环境 ② 抗特化的多样性缓冲）**v1.14/v1.15 一条都没碰**——它们回头补的是信誉门槛，且在单步任务上。

**一句话：v1.15 是"机制可信度"的正结果，不是"可持续生长"的正结果。信誉债还清了，蓝图正中央（F1/F2）仍是硬骨头。**

## 六、增补（v1.16）：第一次真去攻 F1，撞上一堵结构墙

v1.14/v1.15 还的是信誉债（机制可信度），没碰蓝图正中央。v1.16 是 Jayson 交出方向盘后，我**第一次真去攻 §三 的第一条腿（F1：换个"学不完"的环境，看结晶能不能持续）**。

**做法（最小单变量对照）：** 只把"世界大小"这一个旋钮拧大，其余 v1.13 的物理常数、漂移网格、随机种子**一个都不动**。
- **小世界（8 通道）**：全部"催化剂对"只有 28 种，装得进 40 的预算 → **能学完（可饱和）** → 应复现 F1（学会就冻住）。
- **大世界（64 通道）**：催化剂对有 2016 种，远超 40 → **学不完（组合开放）** → 应能一直结晶新东西。

**结果（多 seed 跑一次，如实报）：撞墙了。**
- 只有"环境完全不变（drift=0）"时两个世界都活着：小世界饱和冻住（＝F1 签名，如期复现），大世界虽活却**一个新催化剂都没铸出**（环境不变＝没有新信息进来，正是 OC-12 说的"没有环境门就没有生长"）。
- **只要环境一动（任意 drift>0），两个世界的 agent 全死**，库从 40 个催化剂塌到只剩 1~4 个。

**为什么死（机制诊断，第一档 measured）：** 为了让"大世界学不完"，我用了**特异的**催化剂（必须同时匹配两个通道才算成功）。可环境一漂移，这些特异催化剂大多变成"差一点匹配"——**差一点也算被触发去点火，点火就失败，失败就被罚、被遗忘**。于是库在任何变化下**自己把自己拆了**，而重建一个催化剂需要的次数比预算耗尽还慢。

**⇒ 真正的产出：把 F1 磨利了。** 原来 F1 只说"世界太小→学完就冻"。v1.16 撞出的更深的墙是：

> **在"子集匹配"这套机制下，"学不完"和"追得上"是互斥的。**

- 想让世界**学不完**（开放）→ 必须用**特异**催化剂；
- 想在**变化中活下来**（追得上）→ 必须用**泛化**催化剂（v1.13 那种单通道、差一点也不会被罚死的）；
- 特异催化剂"差一点就被罚死"，库留不住多样储备；泛化催化剂又能学完任何世界（＝F1 本身）。
- **光把世界拧大逃不出这个两难**，只是换个地方卡住。

**F1 升级成 v1.17 的机制要求（已登记，没擅自续跑）：** 可持续结晶需要一个**既学不完、又追得上**的可行空间；靠"放大子集匹配的世界"给不出。必须**把"开放性"和"催化剂特异性"解耦**，三条候选腿：
1. **组合层级**：用泛化而稳健的基础催化剂，让它们**无上限地组合**成越来越高阶的催化剂——开放空间靠"组合爆炸"，而不是靠一堆脆的特异基元（像化学：少数稳定原子组合出无穷分子）。
2. **别把"差一点"罚到死**：改匹配/遗忘规则，保护一个多样的储备库（正好接上 F2 的"抗特化缓冲"）。
3. **环境的新颖性是"组合性"的**：新东西是"熟悉特征的新组合"，而不是"更多陌生通道"。

**守住的纪律（这次尤其关键）：** smoke 一试就看出两臂全死的设计错位——**但我没有去搜一个"能活的世界大小"来凑出想要的结果**（那正是 K-NO-TUNE-TO-WIN 明令禁止的"重扫参数造带"）。我**照预注册的网格老老实实跑一次，如实报 H-NO-ISOLATION，把失败当主产出**。同时诚实认领：**跑前的组合核算是个漏项**（只验了"学不完 + 必须适应"，没验"漂移下追不追得上"），是 smoke 在过度投入前把它抓出来的——纪律生效了，但这份预注册设计确属误校准。

一句话：**v1.16 没攻克 F1，但第一次把 F1 从"世界太小"精确成"开放性与可追踪性互斥"，并给出 v1.17 必须解耦的三条腿。这是"错误也是学习"再次兑现——失败的仪器产出了更利的理论。**
