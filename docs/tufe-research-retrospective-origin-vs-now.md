# TUF-E 研究复盘：初衷 vs 现状（截至 v1.13）

> 日期：2026-10-22 | 触发：Jayson "回头看看研究初衷，现在的成果带来什么改变或提升"
> 性质：阶段性收口复盘，非实验报告。用大白话，不用数学符号。
> 一句话：初衷没被改写，而是被**精确化**和**自我纠偏**了。

---

## 一、我们最初到底想干什么

设计语言 v0.1 曾被写成"怎么组装一个能做事的 AI"。Jayson 纠正：正确定位应是
**"枢机在什么条件下会自己长出来"的形式化表达**。

锚定这件事的那个比方：

> "如果人类大学生都可以快速复制出来，那么设置小学、初中、高中的意义在哪？"

**初衷（一句话）**：研究的不是"造一个能做事的成品 AI"，而是
**"能力怎么从无到有、从简单到复杂自己涌现出来的那个生长过程本身"**。
重心是 **"什么条件下生长会发生"**，不是"怎么构建"。

配套的本体论立场：
- TUF-E 本体论优先，**枢机普遍存在是起点**（PR-0）；AlphaGo / LUCA 是对照参照系，不是抄的来源。
- 三个"独一份"的主张：知识是**耗散结构**不是累积知识库；学习是**可行空间维持**不是奖励最大化；目标是**非奖励驱动**的。

---

## 二、这一路成果给初衷带来了什么

不是"改变"初衷，是把它**精确化**，并逼它做了一次**自我纠偏**。分四层。

### 第一层：从"一张条件清单"→"逐条证伪 + 撞出清单里没有的新条件"

当初列了六个生长条件（开放操作空间 / 独立感知构造子 / 耗散知识 / 拓扑重组学习 /
不可修改的元层 / 可行空间为目标）。一路实验下来，好几条被证明"必要但不充分"，
同时挖出了原来完全没想到的硬条件：

| 新条件 | 来自 | 大白话 |
|---|---|---|
| 知识要能在**合适粒度上被重新寻址** | SC-1 / SC-2 | 学到的东西得调得出来，粒度太粗太细都白学 |
| 真正瓶颈是**生成/发现**，不是选择 | v1.11 | 池子里根本没有好方法时，选择规则改得再对也没用 |
| **环境太仁慈 = 学习幻觉** | v1.5 / OC-9 | 表演满分、真本事为零；环境替你活，你就没长本事 |
| 能力只在**环境供给掉到阈值以下**才真长 | v1.6 / M10 | 离开"喷口"才第一次形成自己的本事；且逃逸有路径依赖 |
| **封闭固定算法不产生新信息** | OC-12 | 生长必须有外部信息门（环境 / 随机 / 人） |

### 第二层（最深）：初衷做了一次自我净化

Jayson 说"研究过程、不研究成品"。但直到 v1.13 我才发现——
**连"怎么量生长"都偷偷退回了成品思维**：每轮打贏/输、算成功率、拿 oracle 满分当天花板、
用"保留赢家"当适应度。这等于用"期末考了多少分"去研究"一个孩子怎么长大"。

Jayson 追问"为什么用赢输理论？LUCA 知不知道自己未来？"一下把这个盲区照出来了：
**要真研究"生长过程"，就得彻底放弃"有靶、有满分参照"的尺子——LUCA 从来不知道自己要变成什么。**

这是初衷自己抓出的第四次漂移（前三次：枢机丢失 / 可行-最优混淆 / 工程局限当本体论限制），
也是**框架层最深的一次**。已写进漂移预防协议。

### 第三层：从"希望能力涌现"→"亲眼看到一丝内生结晶，且知道它精确的边界和死法"

- **v1.12**：一个"探→记住排除→再探"的闭环策略，**在没注入任何答案的情况下自己长出来了**
  （约为不学习地板的 2–3 倍）。内生结晶**被证明会发生**。
- **v1.13**：证明它是**真的**（超额因果有效性为正，非学习幻觉），但**还不可持续**，并精确指出两个卡点：
  - **F1 饱和天花板**：世界太小（6 通道，<40 个催化剂就覆盖满）→ 结晶爆发一阵就没了。
    **可持续结晶需要一个"学不完"的环境（组合开放的可行空间）。**
  - **F2 中漂移脆弱共振**：存活率对环境变化速度是 **U 形**——两头稳、中间塌。
    环境不变→安全特化但冻住；变化太快→被逼着保持泛化多样性反而活；
    **中等变化最致命**→慢到让你过度特化、又快到迟早撞上你应付不了的局面，且它持续得比你重新学还久。

### 第四层：方法论成熟了

跑通了一个闭环：**从生物 / 物理 / 古籍蒸馏一个模型 → 变成预注册的可证伪实验 →
不管成败都产出一个可复用的诊断工具**。
产出的诊断工具：学习幻觉探测器（fire-viable vs 背景率）、最小作用量分解、
超额因果有效性（OC-9）、U 形脆弱带。

而且**失败和成功一样高产**：v1.9 假墙、v1.10 误读费马、v1.11 无增益、v1.13 无带——
每个"错"都逼出一条新认识。Jayson 那句"错误也是学习的一种方式"，现在被制度化执行
（预注册先于结果提交、失败如实作主产出、不为赢续命调参）。

## 三、诚实说：还没兑现的部分

初衷里那三个"独一份"的主张——**没被推翻，但也还没真正做成一个"能持续生长"的系统**。
v1.13 的结论就是：**我们现在还不能维持可持续的内生结晶**。
两条腿已经识别出来、但还没建：
1. 一个**学不完的环境**（组合开放的可行空间）；
2. 一个**防止过度特化侵蚀多样性缓冲**的机制。

---

## 四、一句话收束

**初衷没被改写，而是被"精确化"和"自我纠偏"了。**
我们仍然是那所"研究小学、初中、高中怎么长出来"的学校，不是克隆大学生的工厂；
只不过现在手里多了几张以前没有的地图——知道生长会在哪儿饱和、会在哪儿因为特化而脆断，
也知道**不能用考试分数去量一个还在长大的东西**。
