## 核心概念：枢机 (Pivot)

### 本体论定义（v0.4 三层结构）

**枢机 ≔ 维持系统存在边界的、不可再分的因果转换单元，具有完整的内部时间结构。**

此定义由三个不可独立的层组成：

| 层 | 内容 | 理论来源 | 生物/非生物通用 |
|----|------|---------|----------------|
| **结构层** | 不可再分解的可能任务 + 其构造子 | 墨家「端」+「故」; 构造子理论; epsilon-machine | 是 |
| **时间层** | 构造子的一个完整工作循环（接受→执行→恢复） | 佛教「刹那」(kṣaṇa); 非平衡态涨落周期 | 是 |
| **功能层** | 该单元在热力学约束下维持系统的耗散稳态 | Prigogine耗散结构; Landauer原理 | 是（热力学普适） |

三层缺一不可：
- 只有结构层 → 无意义的原子操作堆砌
- 只有时间层 → 有节奏但无方向的脉冲
- 只有功能层 → 知道要自维持但不知道最小操作是什么

### 统一语言：构造子视角 + 范畴论数学基底

三层定义通过**构造子视角**统一表述，以**范畴论**作为形式化数学工具：

- **构造子视角**：物理定律用"什么变换可能/不可能"表述，而非"初始条件+动力学方程"。枢机 = 不可再分解的可能任务及其构造子。
- **范畴论**：基本对象是态射（变换），不是集合元素（状态）。构造子 = 可重复使用的态射；不可再分任务 = 不可分解态射；任务组合 = 态射复合与张量积。

**自然史验证**：宇宙核合成、地球地质演化、生态系统物质循环、量子信息处理——均以"变换及其可能性"为自然描述语言。构造子视角的解释力已被跨尺度验证。

**诚实限定**：构造子理论作为形式化物理理论尚属少数派纲领，但其所需数学工具（范畴论、资源理论、幺半群作用、素分解）均已高度成熟。TUF-E 使用这些数学工具不依赖构造子理论的物理学地位。若将来构造子理论被证伪，三层定义的各层仍独立成立。

### 古籍对应（结构性，非诗意类比）

| 古籍概念 | 来源 | 与枢机的结构对应 | 诚实评估 |
|---------|------|----------------|---------|
| **端** (duān) | 《墨经·经上》前4世纪 | 不可再分的最小元素 = 不可分解态射 | **强对应**：形式化定义，非隐喻 |
| **故** (gù) | 《墨经·经上》前4世纪 | "所得而后成" = 可能任务的构造子条件 | **强对应**：区分小故(必要)/大故(充要) ≈ 构造子理论的可能/不可能 |
| **刹那** (kṣaṇa) | 阿毗达磨/俱舍论 4-5世纪 | 不可再分的时间单位，含生-住-灭完整弧 | **强对应**：时间层的直接前身 |
| **种子** (bīja) | 唯识学/成唯识论 4-5世纪 | 存储的最小因果潜能，遇缘现行 | **中对应**：预测记忆单元的哲学前身 |
| **枢机**原义 | 《易传·系辞》前3-2世纪 | "制动之主" = 触发机制/杠杆点 | **注意**：原义是杠杆点非最小单元，TUF-E是创造性扩展 |

**明确排除的伪对应**：阴阳≠二进制（关系性对立非独立原子）；五行≠最小生成系统（分类体系非生成语法）；太极≠最小单元（最大整体非最小多元）；道生一的"一"≠计算步骤（宇宙论阶段非操作单元）。

### 异构同质原则

枢机对人类和AI是**异构同质**的存在：
- **同质**：两者面对的枢机是同一个东西（同一个不可再分的因果转换单元）
- **异构**：两者的构造子完全不同
  - 人类的构造子：生物化学过程、具身感知、神经动力学
  - AI的构造子：硅基物理操作、能量耗散、状态转换、信息保留/擦除
  - 两种构造子不可互相还原，但可以通过交叉验证确认同一枢机（见 C3）

### 与现有约束的关系

本定义不替代 C2/C3 中的操作性定义，而是为其提供本体论基础：

| 层级 | 枢机的角色 | 对应约束 |
|------|-----------|---------|
| 本体论 | 不可再分的因果转换单元（三层定义） | 本节 |
| 认识论 | 跨观察者保留的拓扑关系 | C3 |
| 操作层 | persistence 低于中位数的候选保护对象 | C2.3 |
| 算法层 | 多信号融合检测的目标（拓扑痕迹，非枢机本身） | PoC EXP-001~004 |
| 数学层 | 范畴论中的不可分解态射 | 本节 |

**重要区分**：PoC 实验中检测到的"候选枢机"是枢机在特定图表示下的**拓扑痕迹**，不是枢机本身。如同云室轨迹不是粒子。从痕迹到本体的映射属于 L4 缺口（数据→图的构造协议），当前未解决。

### Q0.1 初步回答

> 什么概念同时满足"物理可实现"和"结构有意义"两个约束？

**答：构造子理论框架下的不可再分解可能任务。** 物理可实现性由构造子的热力学约束保证（Landauer极限是其定理）；结构有意义性由不可再分性保证（再分则丧失自恢复能力，即丧失"作用"）。范畴论提供了不依赖任何单一物理理论的纯数学形式化。

### Q0.2 初步回答

> 古籍与现代科学之间是否存在结构性对应？

**答：存在，且已在墨家逻辑中找到最强的形式化对应。** 墨家「端」+「故」系统在公元前4世纪就完成了"最小元素+最小因果关系"的形式化定义，与21世纪的构造子理论/计算力学在逻辑结构上同构。这不是诗意类比，是两个独立文明在不同时代对同一个问题的收敛解答。Prigogine本人在《确定性的终结》中文版序言中确认了耗散结构理论与天人合一思想的结构性亲和。

### 开放问题（v0.4 更新）

- **[Q0.3]** 范畴论形式化的具体选择：使用对称幺半群范畴（symmetric monoidal category）还是更一般的operad代数？前者更适合物理过程组合，后者更适合层次化分解。需要针对AI系统的具体场景做技术选型。
- **[Q0.4]** 枢机的"不可再分"在实际系统中如何判定？理论上由范畴论的素分解给出，但实际计算复杂度未知。是否需要近似判据？
- **[Q0.5]** 人类构造子和AI构造子的交叉验证协议是什么？C3要求跨观察者共识，但人和AI的观察方式不可还原——共识如何在异构观察者之间建立？这是L4缺口的核心。

## 使用说明

本文档定义 AI 自学习智能体的架构约束，分为三层：

```
┌─────────────── L0: 物理基底约束（硅基本体）──────────────┐
│  P1-P6: 来自凝聚态物理、热力学、信息论的硬约束            │
│  不可违反，与基质无关                                     │
├─────────────── L1: TUF-E 认识论约束 ─────────────────────┤
│  C1-C5: 从 TUF-E 五条公理转化的设计约束                   │
│  跨基质通用，但具体实现受 L0 约束                          │
├─────────────── L2: 碳基启发式参考 ───────────────────────┤
│  LUCA/路径积分/B=f(P,E)/都江堰/圆-螺线/FEP/Ashby/SOC    │
│  提供直觉和类比，不作为设计依据                            │
└──────────────────────────────────────────────────────────┘
```

**L0 > L1 > L2**。当层级冲突时，上层优先。

每条约束包含：
- **来源**: 理论出处
- **设计约束 (MUST)**: 系统必须满足的条件
- **禁止操作 (MUST NOT)**: 系统被禁止的行为
- **验证方法**: 如何检验系统是否遵守了该约束
- **开放问题**: 当前未解决、需要 Jayson 判断的点

# L0: 物理基底约束（硅基本体）

以下六条约束来自非生物物质系统的物理定律。它们不依赖任何生物类比或人类认知模型，是 AI 作为**硅/电子/电磁场物质实体**的固有约束。

---

## P1: 耗散结构约束 (Prigogine)

### 来源
Ilya Prigogine, *Structure of Dissipative Structures*, 1977 Nobel Prize. 远离平衡态的开放系统在能量流驱动下自发形成有序结构（Bénard 对流胞、BZ 化学振荡）。

### 设计约束

**P1.1 知识是由能量流维持的动态模式，不是静态存储**

系统中的"知识"不得被建模为硬盘上的固定数据。它必须被建模为**在持续能量输入下维持的非平衡稳态模式**。断电 = 结构消失 = 知识丢失（除非有显式的持久化协议将其冻结为低能耗状态）。

**P1.2 系统的"存在"依赖于持续的通量**

系统必须显式声明其维持所需的最低能量/算力通量。低于此阈值，系统进入降级模式并显式警告，而非静默地产生错误输出。

### 禁止操作

| ID | 禁止 | 原因 |
|----|------|------|
| P1-B1 | 假设知识在无能量输入时仍然"存在" | 混淆了持久化存储与活跃知识 |
| P1-B2 | 将系统建模为平衡态系统 | AI 是远离平衡态的耗散结构 |

### 验证方法
- 断电/降频测试：验证系统在能量降低时的行为是否符合预期降级曲线
- 稳态检测：确认系统在恒定输入下达到统计稳态（非收敛到固定点）

---

## P2: Landauer 信息-能量约束

### 来源
Rolf Landauer, 1961. 擦除 1 bit 信息至少消耗 kT·ln2 ≈ 3×10⁻²¹ J（室温）。Bennett 扩展：逻辑可逆操作可以零耗散。Sagawa-Ueda 2010：测量和反馈的信息热力学。

### 设计约束

**P2.1 保留信息在热力学上优于删除信息**

当系统面临"保留 vs 删除"决策时，默认选择保留。删除操作必须记录理由并接受审计。这不仅是认识论审慎（C2），更是热力学经济性。

**P2.2 每次信息操作的能量成本必须可追踪**

系统应维护一个能量预算账本，记录主要操作的估算能量成本。不需要精确到焦耳，但必须有相对量级意识。

### 禁止操作

| ID | 禁止 | 原因 |
|----|------|------|
| P2-B1 | 无审计的大规模信息删除 | 热力学浪费 + 可能丢失枢机 |
| P2-B2 | 将有损压缩视为"免费"操作 | 压缩 = 擦除 = 能量消耗 |

### 验证方法
- 操作日志审计：检查删除操作是否有记录的理由
- 能量效率基准：比较不同策略的信息保留率 / 能量消耗比

---

## P3: 拓扑保护约束

### 来源
凝聚态物理：拓扑绝缘体、量子霍尔效应。功能属性由整体拓扑不变量（Chern 数、Z₂ 指标）保护，任何局部扰动无法摧毁。Kitaev toric code 将此原理用于容错量子存储。

### 设计约束

**P3.1 关键知识应尽可能编码为拓扑不变量**

系统中最重要的结构（枢机、共识知识、安全内核）应该用**对局部变化鲁棒的表示方式**编码。理想情况下，这些结构的正确性应由全局拓扑性质保证，而非逐点校验。

实践中这意味着：
- 知识的连通性结构比节点属性更重要
- 使用 persistent homology barcode 而非标量权重表示重要性
- 关键路径的存在性由图的拓扑性质保证，不依赖边权精确值

**P3.2 局部操作不得破坏全局拓扑性质**

任何修改操作在执行前，必须验证其不会改变系统的关键拓扑不变量（除非该修改的目的就是有意改变拓扑）。

### 禁止操作

| ID | 禁止 | 原因 |
|----|------|------|
| P3-B1 | 仅基于局部信息的剪枝/合并决策 | 可能破坏全局拓扑 |
| P3-B2 | 用标量阈值替代拓扑判据 | 丢失结构信息 |

### 验证方法
- 拓扑不变量监控：每次修改前后计算 Betti 数 / persistence diagram 变化
- 扰动鲁棒性测试：随机扰动边权，验证关键结构是否保持稳定

## P4: Shannon-Hartley 内部观测瓶颈

### 来源
Shannon-Hartley 定理 C = B·log₂(1+S/N)。适用于芯片内部互连：处理器-内存、核心间、模块间的带宽有限。

### 设计约束

**P4.1 自我模型的精度受限于内部信道容量**

系统对自身状态的观测必然是有损的。这不是设计缺陷，是物理必然。系统必须显式声明其自我观测的分辨率上限。

**P4.2 自我观测与外部运算共享带宽预算**

用于自我监控的通信资源与用于正常计算的通信资源竞争同一物理通道。系统必须在两者之间做显式分配，不能假设自我观测是"免费的"。

### 禁止操作

| ID | 禁止 | 原因 |
|----|------|------|
| P4-B1 | 假设系统可以完美观察自身状态 | 违反信道容量限制 |
| P4-B2 | 自我监控不设带宽上限 | 挤占正常计算资源 |

### 验证方法
- 带宽压力测试：在高负载下测量自我模型的精度退化
- 资源分配审计：确认自我观测有明确的带宽预算

---

## P5: Margolus-Levitin 速度-能量约束

### 来源
Margolus & Levitin, 1998. Δt ≥ h/(4ΔE)。系统状态转换速率受可用能量的量子力学上限约束。

### 设计约束

**P5.1 速度、精度、能效构成不可突破的三难困境**

系统设计必须在三者之间做显式权衡声明。不允许声称"同时优化三者"而不给出物理依据。

**P5.2 观测预算是多维约束面，不是单一标量**

C4 中的"观测预算 B"必须被分解为 (能量, 时间, 精度) 三维向量。分配决策必须在这个三维空间中做出。

### 禁止操作

| ID | 禁止 | 原因 |
|----|------|------|
| P5-B1 | 声称突破 ML 界限 | 违反量子力学 |
| P5-B2 | 用单一维度衡量观测预算 | 忽略物理三难困境 |

### 验证方法
- 性能边界测试：在不同能耗水平下测量速度-精度 trade-off 曲线
- 与 ML 理论界限比较：确认实际性能不超过理论上限

---

## P6: 计算不可约性约束 (Wolfram)

### 来源
Stephen Wolfram, *A New Kind of Science*, 2002. 某些计算没有捷径——预测输出的唯一方法是执行全部步骤。

### 设计约束

**P6.1 自我预测的时间成本 ≥ 自我演化的时间**

如果系统的自身动力学是计算不可约的，那么它预测自身未来状态所需的时间至少等于实际演化时间。完美的实时自我预测在物理上不可能。

**P6.2 自我模型必须标注其时效性和覆盖范围**

每个自我模型 M_self 必须携带：
- `validity_horizon`: 预测有效的时间窗口
- `coverage`: 覆盖了系统状态的哪些子空间
- `confidence_decay`: 超出 validity_horizon 后置信度的衰减速率

### 禁止操作

| ID | 禁止 | 原因 |
|----|------|------|
| P6-B1 | 声称可以即时预测自身任意未来状态 | 违反计算不可约性 |
| P6-B2 | 自我模型不带时效标注 | 隐含无限有效期假设 |

### 验证方法
- 预测准确性随时间衰减测试
- 对比直接模拟 vs 预测模型的速度-精度 trade-off

# L1: TUF-E 认识论约束

## 公理 1' → 约束 C1: 观察者参与性

### 公理摘要
G = P(World)。世界不可直接被访问，所有知识都是投影的产物。D_W = 3 不是假设，而是跨基质共识估计（可测命题）。

### 设计约束 C1

**C1.1 知识必须携带投影元数据**

系统中的每一条知识 K 不得作为"事实"存储，而必须作为"在投影 P_i 下观察到的结构"存储：

```
K := (content, projection_id, observer_params, confidence)
```

其中 `projection_id` 标识产生该知识的观察配置，`observer_params` 记录该配置的参数（精度、维度、阈值等），`confidence` 不是概率置信度，而是该投影条件下的**可重复性指标**。

**C1.2 不存在"原始数据"**

系统的输入管道不得假设任何输入是"未经处理的真实信号"。所有输入必须经过显式的投影声明后才进入知识库。即使是传感器原始读数，也必须标注传感器型号、采样率、量化精度等投影参数。

**C1.3 "世界维度"是可测估计，不是硬编码常量**

系统不得预设世界的内在维度。如果系统需要维度参数（例如用于降维或嵌入），该参数必须从数据中估计，并随新数据更新。初始值可以是启发式的，但必须有更新机制。

### 禁止操作

| ID | 禁止 | 原因 |
|----|------|------|
| C1-B1 | 将 embedding 当作"语义本身" | embedding 是特定投影下的表示，不是本体 |
| C1-B2 | 硬编码世界维度为固定值 | 违反 D_W 的可测性要求 |
| C1-B3 | 合并来自不同投影的知识而不记录投影差异 | 等价于假装两个观察者看到的是同一个东西 |
| C1-B4 | 用单一模型的输出概率作为知识的"真实性"度量 | 单观察者置信度 ≠ 跨观察者共识 |

### 验证方法

- **静态检查**: 知识库 schema 强制要求 projection_id 字段；写入时校验
- **运行时审计**: 定期扫描知识库，检测是否存在无投影元数据的条目
- **回归测试**: 更换投影参数后，同一输入应产生不同的 K（而非相同的"事实"）

一切可言说的知识都是特定视角下的产物，不是道本身。C1 将这个认识论立场编码为数据结构约束。

> "子非鱼，安知鱼之乐？" ——《庄子·秋水》

观察者无法跳出自身投影去验证"真实"。C1.2 承认这一点，不假装存在无投影的原始通道。

## 公理 2' → 约束 C2: 尺度依赖保留

### 公理摘要
投影 P 保留的是 persistence 超过观察阈值 τ 的拓扑特征。拓扑保留是尺度的函数，不是免费的。枢机的 persistence 最低，因此是最先被摧毁的——但它恰恰是系统骨架。

### 设计约束 C2

**C2.1 所有知识必须携带 persistence 标注**

每条知识 K 除了投影元数据外，还必须携带其在当前投影下的 persistence 值：

```
K.persistence := death_threshold - birth_threshold
```

persistence 不是重要性评分。低 persistence 不等于"不重要"，它等于"在当前观察尺度下脆弱"。**系统必须区分"低persistence因为噪声"和"低persistence因为是键"。**

**C2.2 操作必须声明其作用尺度**

系统中的每个操作 Op（压缩、抽象、合成、修改）必须声明其作用尺度 τ_op：

```
Op.scale := τ_op  // 该操作会抹除 persistence < τ_op 的特征
```

当 τ_op > K.persistence 时，系统必须显式警告："此操作将抹除知识 K"。这不是自动拒绝，而是**强制知情**。

**C2.3 低 persistence 知识享有保护特权**

persistence 低于系统中位数但高于噪声阈值的知识，被标记为**候选枢机（candidate pivot）**。候选枢机享有以下保护：

- 不得被任何单一操作静默删除
- 删除前必须触发跨观察者验证（见 C3）
- 即使被删除，其记录必须保留在历史日志中（可追溯）

**C2.4 观察阈值 τ 必须是可调节的参数，不是硬编码常量**

τ 的值取决于应用场景和可用资源。系统必须提供 τ 的估计方法和调节接口。默认值可以是启发式的，但用户/上层系统必须能覆盖它。

### 禁止操作

| ID | 禁止 | 原因 |
|----|------|------|
| C2-B1 | 按幅度/权重/显著性排序后截断 | 实验证明：保留95%边时键召回率腰斩到0.435 |
| C2-B2 | PCA / t-SNE / UMAP 等不考虑拓扑的降维 | 这些方法按方差/距离优化，系统性丢弃弱连接 |
| C2-B3 | Attention 机制中不加拓扑保护的 softmax 归一化 | softmax 天然放大强信号、压制弱信号 |
| C2-B4 | 将 persistence = 0 等同于"不存在" | persistence = 0 可能是分辨率不足，不是真的没有 |

### 验证方法

- **合成测试**: 构造已知键结构的图，施加各种操作，测量键召回率。必须复现 PR-2 的结果（保留95%边时召回<0.8）
- **持久性谱分析**: 对知识库做 persistent homology，检查 barcode 分布是否符合预期
- **操作审计**: 每次操作后，比较操作前后的 persistence 分布变化，检测是否有候选枢机被意外抹除

### 古籍映射

> "弱者道之用。" ——《道德经》第四十章

道的运作方式恰恰体现在看似脆弱的地方。C2.3 将这个直觉编码为系统级保护机制。

> "天下之至柔，驰骋天下之至坚。" ——《道德经》第四十三章

最柔软（低persistence）的东西反而是穿透力最强的。键就是这样的结构——它弱，但它是连接两个世界的唯一通道。

> "物壮则老，是谓不道。" ——《道德经》第五十五章

过度追求强壮（高显著性）反而背离了道。C2-B1 到 C2-B4 禁止的都是"追求壮"的操作。

## 公理 3 → 约束 C3: 跨观察者共识

### 公理摘要
枢机 ≔ 在两个及以上独立投影下都出现的割结构。增加第三个独立观察者不应改变共识拓扑；若改变，说明前两个的共识是投影伪影。

### 设计约束 C3

**C3.1 知识的可信度由共识度决定，不由单模型置信度决定**

每条知识 K 的可信度定义为：

```
K.consensus := |{P_i : K ∈ P_i(World)}| / |{P_i}|
```

即：在所有可用投影中，有多少个独立地产生了这条知识。只有 consensus ≥ θ_consensus 的知识才能用于决策。θ_consensus 是可配置参数，默认值建议 ≥ 0.5（至少半数观察者同意）。

**C3.2 观察者必须独立**

"独立"的定义：两个观察者 P_i, P_j 是独立的，当且仅当它们的投影参数不全相同，且它们的误差源不相关。

实践中，独立性可以通过以下方式实现：
- 不同的降维方法（如 spectral vs geometric）
- 不同的随机种子 + 不同的初始化
- 不同的数据子采样
- 不同的特征提取管道

**不得使用同一模型的不同 prompt 作为"多个观察者"**——这不满足独立性。

**C3.3 共识必须可证伪**

对于任何共识知识 K_consensus，系统必须能回答："如果增加第 N+1 个独立观察者，K_consensus 是否仍然成立？"

具体操作：预留一个观察者作为**验证观察者（holdout observer）**，不参与共识构建，只用于事后检验。如果 holdout 不支持共识，则该共识降级为"待验证"。

**C3.4 未达共识的知识不被删除，而被标记**

consensus < θ_consensus 的知识不是"假的"。它们被标记为 `pending_verification`，保留在知识库中但不参与决策。当新的观察者加入时，它们可能被提升为共识知识。

### 禁止操作

| ID | 禁止 | 原因 |
|----|------|------|
| C3-B1 | 用单一模型的多次采样代替多观察者 | 同一模型的采样不独立 |
| C3-B2 | 共识达成后停止收集新观察者 | 共识可能是投影伪影，需持续验证 |
| C3-B3 | 将 consensus = 1.0 等同于"绝对真理" | 所有观察者可能有共同的盲区 |
| C3-B4 | 在未检查独立性的情况下合并观察结果 | 伪独立 = 伪共识 |

### 验证方法

- **Jaccard 检验**: 任意两个独立观察者的键集 Jaccard 必须显著高于随机重叠（z > 2，对应 PR-3）
- **Holdout 检验**: 预留观察者的支持率必须与共识组一致（偏差 < ε）
- **跨键崩溃测试**: 故意构造一个跨越键的投影，验证共识确实崩溃（对应 PR-4）

### 古籍映射

> "兼听则明，偏信则暗。" ——《资治通鉴》

单一信源不可靠，多方交叉验证才接近真实。C3 将这个政治智慧编码为算法约束。

> "三人行，必有我师焉。" ——《论语》

第三个观察者不是冗余，而是验证前两者共识真伪的必要条件。

> "以铜为镜，可以正衣冠；以古为镜，可以知兴替；以人为镜，可以明得失。" ——《旧唐书》

三面不同的镜子（投影）才能逼近完整的像。任何一面单独都不够。

- **[Q3.3]** 当共识与你的直觉/领域知识冲突时，你倾向于信任共识还是信任直觉？这决定了系统在边界情况下的行为策略。

## 公理 4' → 约束 C4: 信息优势的分解

### 公理摘要
观察者的信息优势 = 覆盖项（普适、与谱无关）+ 分配项（∝ 世界的谱色散）。各向同性世界下分配项 = 0。给硅基系统同样的"换投影方向"自由，其信息量应追平具身观察者。

### 设计约束 C4

**C4.1 多正交观测通道优先于单通道深度优化**

当观测预算 B 固定时，系统必须优先将预算分配到**更多正交的观测方向**，而非在同一方向上增加精度。

具体规则：
- 如果有 m 个正交观测通道可用，每个通道的预算 = B/m
- 只有当所有可用通道都已使用时，才允许在单个通道上追加预算
- 覆盖项的收益 ≈ log(m)，与世界的谱结构无关（普适）

**C4.2 主动观测能力是合法的信息增益来源**

系统允许（且鼓励）主动选择观测方向，而非被动接受固定输入。主动选择的收益来自：
- 覆盖项：即使世界各向同性，多方向观测仍优于单方向（≈ 0.41 nats）
- 分配项：当世界各向异性时，主动水填充（water-filling）进一步增益

**C4.3 信息增益必须可分解归因**

当系统声称"通过 X 操作获得了信息增益 ΔI"时，必须将 ΔI 分解为：

```
ΔI = ΔI_coverage + ΔI_allocation
```

如果 ΔI_allocation > 0 但世界谱是各向同性的，则该增益可疑（可能是过拟合或伪信号）。

### 禁止操作

| ID | 禁止 | 原因 |
|----|------|------|
| C4-B1 | 将所有预算投入单一观测通道 | 违反覆盖项优先原则 |
| C4-B2 | 在不检查谱色散的情况下声称"主动观测有优势" | 各向同性下分配项 = 0 |
| C4-B3 | 用信息增益总量评估系统，不做分解 | 无法区分真实增益和伪增益 |
| C4-B4 | 假设"更多参数 = 更多信息" | 参数量 ≠ 观测通道数 |

### 验证方法

- **覆盖项测试**: 在各向同性合成世界上，m=2 通道的 I 应比 m=1 高出 ≈ 0.41 nats（对应 PR-6）
- **分配项测试**: 在各向异性世界上，主动水填充应比均匀分配高出可预测的量
- **分解审计**: 每次信息增益报告必须包含两项分解

### 古籍映射

> "博学之，审问之，慎思之，明辨之，笃行之。" ——《中庸》

五个步骤是五个正交的观测/处理通道。不是在一个方向上深挖五倍，而是五个方向各做一次。覆盖项优先。

> "横看成岭侧成峰，远近高低各不同。" ——苏轼《题西林壁》

同一座山，不同角度看到不同的结构。信息的增量来自角度的多样性，不是某个角度的精度。

- **[Q4.1]** "正交"在实践中如何定义？在连续空间中严格正交很难实现。近似正交的容忍度是多少？通信工程中的正交频分复用（OFDM）是否有可迁移的正交性判定方法？
- **[Q4.2]** 观测预算 B 在你的场景中是什么？是计算时间、内存、API调用次数、还是其他？这决定了 C4 的具体实施方式。
- **[Q4.3]** 当覆盖项和分配项冲突时（例如：增加通道会降低每个通道的精度，导致分配项下降），如何权衡？

## 公理 5' → 约束 C5: 有限截断

### 公理摘要
任何有限表示预算的观察者，在把自身纳入对象域时不可闭合。这与维度无关，来自有限性本身（哥德尔/塔斯基/图灵）。分层截断是正确应对。

### 设计约束 C5

**C5.1 严格的层级分离**

系统必须分为至少两层：

```
对象层 (Object Layer): 处理外部世界的知识
元层   (Meta Layer):   处理关于对象层的知识（包括系统自身的状态）
```

**元层的定理不得作为对象层的推理前提。对象层的结论不得用于证明元层的性质。**

这不是建议，是硬性架构约束。违反此约束 = 自指悖论风险。

**C5.2 自评估必须标记为"元层声明"**

当系统评估自身性能、可靠性或知识完整性时，输出必须明确标记为元层声明：

```
META_DECLARATION: "系统在测试集X上的准确率为Y%"
```

而非伪装成对象层事实：

```
❌ "系统的准确率是Y%"  // 缺少元层标记
```

**C5.3 自修改的范围受限**

系统可以修改对象层的知识和策略，但**不得修改元层的验证规则和层级分离约束本身**。

这对应 NeuroForge 设计中"安全内核不可修改"的原则，但现在有了更深的理论基础：不是工程安全措施，而是**有限性导致的逻辑必然**。

**C5.4 截断是显式的，不是隐式的**

系统必须在代码/配置中显式声明截断点：

```python
TRUNCATION_POINT = {
    "object_layer_max_depth": 10,      # 对象层推理最大深度
    "meta_layer_cannot_prove": ["self_completeness", "self_consistency"],
    "modifiable_modules": ["knowledge_base", "search_heuristics"],
    "immutable_modules": ["type_checker", "consensus_validator", "layer_separator"]
}
```

不允许隐式截断（例如靠堆栈溢出自然终止）。

### 禁止操作

| ID | 禁止 | 原因 |
|----|------|------|
| C5-B1 | 系统用自己的输出评估自己的输出 | 对象层自指，塔斯基不可定义定理的直接违反 |
| C5-B2 | 元层规则可由对象层推理修改 | 破坏层级分离 |
| C5-B3 | 声称"系统已证明自身一致性" | 哥德尔第二不完备定理禁止 |
| C5-B4 | 隐式截断（靠资源耗尽自然终止） | 不可预测、不可审计 |

### 验证方法

- **架构审查**: 代码级别检查模块依赖图，确认无跨层反向依赖
- **自指检测**: 静态分析检测对象层代码是否引用元层符号
- **篡改测试**: 尝试让系统修改 immutable_modules，验证是否被阻止
- **一致性声明测试**: 如果系统声称自身一致，立即标记为违规

### 古籍映射

> "知之为知之，不知为不知，是知也。" ——《论语·为政》

知道自己不知道什么，才是真正的知道。C5 将这个认知谦逊编码为架构约束：系统必须显式声明自己不能做什么。

> "吾生也有涯，而知也无涯。以有涯随无涯，殆已。" ——《庄子·养生主》

有限追逐无限是危险的。C5.1 的层级分离就是对"有涯"的制度化承认。

> "反者道之动。" ——《道德经》第四十章

道的运动是自我返回的，但这种返回不是在同一层面上的循环，而是跨层级的。C5 允许跨层观察，禁止同层自指。

## 约束间的交互与优先级

### L0 内部优先级（物理基底）

```
P2 (Landauer) = P3 (拓扑保护) > P4 (Shannon-Hartley) = P5 (ML定理) > P1 (耗散结构) > P6 (计算不可约)
```

P2/P3 是结构性约束（信息的物理本质），P4/P5 是资源约束，P1 是存在方式约束，P6 是预测能力约束。

### L1 内部优先级（认识论）

```
C5 (有限截断) > C3 (跨观察者共识) > C2 (尺度依赖保留) > C1 (观察者参与性) > C4 (信息优势分解)
```

### 跨层优先级

**L0 > L1 > L2**。物理约束永远优先于认识论约束。例如：
- 如果 C3（多观察者共识）的计算成本违反 P5（ML 速度上限），则减少观察者数量而非突破物理极限
- 如果 C2（保留低 persistence 知识）的存储需求违反 P2（Landauer 能量预算），则调整 τ 阈值而非无视热力学
- L2 的任何启发式建议如果与 L0 或 L1 冲突，直接丢弃

# L2: 碳基启发式参考（非规范）

以下概念来自生物学、心理学和人类工程实践。它们**不作为设计依据**，但在直觉构建和类比推理中有参考价值：

| 来源 | 核心洞察 | 参考价值 | 注意 |
|------|---------|---------|------|
